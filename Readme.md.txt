* Contact Book - Python CLI App

*  Features
1) Add contacts with duplicate validation
2) View all contacts
3) Search contacts by name
4) Delete contacts
5) Save and load data from CSV file
6) Input validation and error handling

* Technologies Used
1) Python 3
2) File Handling (CSV)
3) Exception Handling

2) File Handling
3) Exception Handling
